📚 CYB102 Theory Study App

An interactive study app I built to make preparing for my CYB102 written exam easier and more engaging.

The app covers the major topics in the Internet and its Application course, organized into units with theory questions and model answers. Students can go through questions one at a time, think about their answers, and reveal the model answer when ready.

✨ Features

- 📖 Unit-by-unit theory questions
- 💡 Reveal/hide model answers
- 📊 Progress tracking
- 🔄 Restart and review options
- 📱 Mobile-friendly design
- 🎀 Clean, soft and student-friendly interface

🛠️ Built With

- HTML
- CSS
- JavaScript
